# Contributing to Neus UI

Thanks for helping. Issues and pull requests are welcome on
[GitHub](https://github.com/KazmerMaximiliano/neus-ui).

- **Bugs:** open an issue with the version, the design system, a minimal reproduction and what
  you expected. Security problems go through the [security policy](./SECURITY.md).
- **Changes:** fork, branch from `main`, and follow the [contributor guides](./docs/contributing/README.md):
  [development](./docs/contributing/development.md), [testing](./docs/contributing/testing.md),
  [authoring design systems](./docs/contributing/design-system-authoring.md) and
  [adding a component](./docs/contributing/adding-a-component.md). Coding agents read
  [AGENTS.md](./AGENTS.md).
- **Before opening a pull request:** run `pnpm lint`, `pnpm design:check`, `pnpm test:unit`,
  `pnpm test:design-systems` and `pnpm build`, and add an entry under `## [Unreleased]` in
  [CHANGELOG.md](./CHANGELOG.md) for user-visible changes.
